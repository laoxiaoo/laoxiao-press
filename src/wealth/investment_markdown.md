
# 职业投资者训练营（20 课）

## 1. 宏观篇

### 资金流向（第1课）
- 四大资产：现金/债券/股票/商品
- 核心：判断资金去向，而非预测股价

### 美林投资时钟（第2课）
- 复苏→股票｜繁荣→成长股｜滞胀→商品｜衰退→债券/现金
- 陷阱："这次不一样"（区分好行业与好价格）

### 宏观六大指标（第3课）
- GDP（滞后）｜PMI（前瞻＞50）｜CPI｜PPI｜M2｜社融
- 方法：每月复盘，连起来看，判断经济阶段

### 利率与央行（第4课）
- 利率=钱的价格；降息救经济≠利好股市
- 降息→老债券涨、股票易涨；关键看降息原因
- 美联储影响全球资金流向

### 美元/黄金/人民币/A股（第5课）
- 美元=全球水龙头；利率决定美元强弱
- 黄金：避险 + 美元周期
- 建立"美联储→美元→资产"因果链

## 2. 商品与行业篇

### 商品周期（第6课）
- 价格=供给×需求
- 黄金=资产（避险+实际利率）；铜=经济晴雨表
- 周期：高价→扩产（5-10年）→供给过剩→暴跌

### 行业轮动（第7课）
- 本质：资金寻找下一个利润增长点
- 六大行业分类及观察变量
- 先选行业，再选公司
- 能力圈：知道自己真正理解什么

## 3. 公司篇

### 资产负债表（第8课）
- 资产=负债+所有者权益；看家底
- 五指标：现金/应收账款/存货/有息负债/净资产

### 利润表（第9课）
- 漏斗：收入→毛利润→营业利润→净利润
- 毛利率=竞争力；利润增长比利润大小重要
- 三陷阱：增收不增利/增利不增现金/一次性收益

### 现金流量表（第10课）
- 利润≠现金；经营/投资/筹资三大现金流
- 自由现金流=经营现金流−资本开支
- 现金流是企业的生命线

### ROE/ROIC/自由现金流（第11课）
- ROE=股东钱效率（高可能靠负债，要看长期稳定）
- ROIC=全部投入效率；普通人看今年，职业看十年

### 护城河（第12课）
- 五大来源：品牌/技术/成本/规模/转换成本
- 验证五指标；利润是结果，优势是原因

### 估值（第13课）
- PE：价格相对利润｜PB：价格相对净资产
- DCF：价值=未来现金流折现
- 好公司≠好买点；安全边际；估值排最后

## 4. 风控与纪律篇

### 仓位管理（第14课）
- 仓位比选股更重要；分批建仓留子弹
- 四阶段：试仓→建仓→持仓→减仓/清仓
- 买前五问；错了也不会毁掉整个账户

### 风险控制（第15课）
- 波动≠风险；真风险=价值永久受损
- 五大风险 + 五个来源 + 七项清单
- 先想错了怎么办，再想能赚多少

### 牛熊应对（第16课）
- 四阶段：熊市→复苏→牛市→泡沫（各阶段策略表）
- 用宏观指标判断阶段；每月五问
- 投资不是预测市场，而是按阶段采取正确策略

### 巴菲特投资体系（第17课，思想核心）
- 七关键词：不亏本金/能力圈/护城河/管理层/合理价格/长期持有
- 七步决策流程，任一为"否"就不买
- 最大秘密=纪律；让时间成为朋友

### 芒格思维模型（第18课）
- 八模型：逆向/能力圈/多学科/长期/概率/复利/心理陷阱/简单
- 避免愚蠢比追求聪明更重要

## 5. 系统篇

### 投资清单/评分卡（第19课）
- 八步检查清单：宏观→行业→公司→财务→优势→估值→风险→仓位
- 投资日志 + 固定流程复盘

### 终身投资系统（第20课）
- 四问：买什么/何时买/买多少/何时卖
- 四类卖出理由；固定研究节奏
- 投资宪法十条；纪律保护你，而非预测
